## Findings and decisions

1. Fixed-values return/post crossing: retained the documented separation. Clarified
   the legacy-only docstring and tested both fixed rejection and legacy crossing.
2. Suppressed call-generator children: guard actual generators; NIL no longer invents
   a shrink capability. Legacy constant behavior remains unchanged.
3. Candidate lookup: bounded graph-prefix hash buckets reduce deep comparisons;
   same-value-p remains authoritative for cycles, sharing, numeric and array types.
   Collisions can retain quadratic worst-case cost; no linear-time guarantee is made.
4. Generator DSL: every misplaced or duplicate top-level :shrink clause is refused
   during macro expansion, including clauses separated by draw forms.
5. Non-rest generation: the retry loop is intentionally for rest intersections.
   Reproduction found invalid custom keyword draws reached the target. Added fail-fast
   initial call validation before invocation. Rest-driven values retain their existing
   single validation, avoiding duplicate predicate execution.
6. Instrument omissions: use published :unresolved-reference/:definition-missing
   and :opaque-definition/:inspection-error combinations, with a vocabulary guard.
7. Wrapper binding: reuse one projection while raw spine identities/CAR values match;
   rebuild after mutation. Preserve deep object identity, post-only ordering and
   active restarts. Diagnostic predicates remain callable over fresh inputs; storing
   their function in an error record never executes them a fourth time.
8. Digest exclusions: one fresh-list function feeds schema-info and definition metadata.
   Existing public key names remain compatible.
9. Incomplete graphs: skip the discarded canonical hash, still scan value omissions.
10. Layout policy: one helper feeds canonical digest fields and public introspection.
    Their enclosing shapes intentionally differ; historical digest bytes are stable.
11. Layout reuse: finite independent declaration/binding snapshots detect mutation and
    accepted reinitialization invalidates the cache. Failed changes restore cache slots.
    Wrapper and public argument schemas get private layouts: caching must not let
    externally changed bindings corrupt an already compiled check.
12. Self-specs: explicit registry imports declare ASDF package dependencies.
13. Tuple rollback slots: the owning IR module supplies its slot protocol.
14. Neutral call modules: corrected two-space indentation.
15. Call-outcome and touched declarations: wrapped long lines.
