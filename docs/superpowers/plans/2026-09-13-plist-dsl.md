# Plist DSL Implementation Plan

> For agentic workers: use superpowers:subagent-driven-development or superpowers:executing-plans task by task.

**Goal:** Implement field-aware plist specifications and migrate executable self-specifications.

**Architecture:** Separate representation-independent field metadata from plist structure checks. Integrate through existing Semantic IR compiler and schema hooks; keep check-it outside core.

**Tech Stack:** Common Lisp, ASDF package-inferred systems, Rove, check-it, cl-mcp REPL.

**Spec:** docs/superpowers/specs/2026-09-13-plist-dsl-design.md

## Global Constraints

- Preserve current worktree changes; core never loads check-it or cl-mcp.
- Use explicit package imports, no runtime eval or dynamic interning.
- Edit existing Lisp forms with cl-mcp structural tools; list new tests in tests.lisp.

## Task 1: Field IR, normalization, validation and explanation

Files: new src/field-spec.lisp and tests/plist-test.lisp; src/normalize.lisp,
src/explain.lisp, src/introspection.lisp, src/schema.lisp, src/function-spec.lisp,
tests.lisp.

- [x] Write table-driven tests: `(:id nil)` satisfies required nullable integer;
  missing `:id` does not. Duplicates, odd/dotted/cyclic inputs and unknown closed
  keys fail. Nested `(:user (:age "bad"))` reports path `(:user :age)`.
- [x] Run `run-tests` on cl-spec/tests/plist-test and observe missing PLIST support.
- [x] Add field-definition key/spec/required-p readers and field-spec fields/closed-p
  readers in src/field-spec.lisp, plus concrete plist-spec and spec-children method.
  Normalize required/optional pairs to these objects with strict clause validation.
- [x] Compile structure checks before child predicates; retain key presence independently
  of value. Add field-path annotations for failure identity.
- [x] Publish field descriptors and child indices in spec-data; digest keys, flags and
  children. Test digest change when keys/required/closed/child specs change.
- [x] Run the focused suite and existing normalization/explanation/schema suites.
